# ワイルドライフ 要件定義書

## 1. ゲーム概要

- **タイトル**: ワイルドライフ (Wildlife)
- **ジャンル**: サバイバル建築シミュレーション
- **世界観**: ほのぼのサバイバルディストピア
- **視点**: 見下ろし視点（トップダウン2D）
- **グラフィック**: 8bitドット絵風
- **プラットフォーム**: PC（ブラウザ）

## 2. ゲームの目的

- 自由に建築を楽しむ
- 村を発展させる
- サバイバル生活を送る

## 3. 操作方法

- 全てマウス操作
- 左クリック: 移動、選択、アクション
- 右クリック: ブロック配置
- 走る操作も可能（方法は実装時に決定）

## 4. 画面・マップ

- 画面サイズ: PC向け（実装時に最適なサイズを設定）
- マップ: スクロールする広いマップ（実装可能な範囲で広く）
- 開始地点: 草原（簡素な家あり）

## 5. キャラクター

### 5.1 プレイヤー
- 見た目: 人間（ドット絵）
- 移動速度: 通常 / 走り（2段階）

### 5.2 敵
- 昼: 動物（倒すと肉が手に入る）
- 夜: モンスター、ゾンビ
- 戦闘: 道具で攻撃、または逃走可能

## 6. ステータス

### 6.1 体力ゲージ
- 減少要因: 空腹、敵の攻撃、環境ダメージ（寒さ・暑さ）
- ゼロになると: 家に強制帰還、強制睡眠
- 回復方法: 睡眠

### 6.2 空腹ゲージ
- 時間経過で減少
- 限界になると: 動けなくなる
- 回復方法: 食事（野菜、肉、料理）

## 7. 時間システム

- 昼夜サイクルあり
- 時間の流れ: 現実の1分 = ゲーム内1時間
- 1日 = 現実の24分
- 睡眠で夜をスキップ可能

## 8. 資源

### 8.1 基本資源
| 資源 | 用途 |
|------|------|
| 石 | 建築、道具 |
| 土 | 建築、農業 |
| 砂 | 建築 |
| 草 | 建築 |
| 木 | 建築、道具 |
| 鉄 | 道具 |

### 8.2 収集方法
- 道具を使用して収集
- 資源は枯渇する（使いすぎるとなくなる）

## 9. 道具

### 9.1 道具の種類（予定）
- ツルハシ: 石、鉄の採掘
- 斧: 木の伐採
- クワ: 畑を耕す
- 武器: 敵への攻撃

### 9.2 道具の入手
- ゲーム開始時: 最低限の道具を所持
- 以降: 材料を集めて錬成

## 10. 建築

- 方式: 地面に間取りを描く（完全見下ろし視点）
- ブロック種類: 石、土、砂、草、木など
- 右クリックでブロック配置

## 11. 家

### 11.1 初期状態
- ゲーム開始時に簡素な家が存在
- 最低限の機能あり

### 11.2 家の機能
- 睡眠（体力回復、夜スキップ）
- 料理
- 道具の収納（収納箱）

### 11.3 拡張
- 自分で建築して拡張可能

## 12. 農業

### 12.1 育てられる作物
- トマト
- かぼちゃ
- なす
- いちご
- さくらんぼ
- もも
- とうもろこし

### 12.2 成長システム
- 成長速度: ゲーム内時間で数日
- 手順: 畑を耕す → 種を植える → 水やり → 収穫

## 13. 食事

### 13.1 食べ物の種類
- 野菜・果物: そのまま食べられる
- 肉: 動物から入手
- 料理: 家で調理（素材を組み合わせる）

### 13.2 効果
- 空腹ゲージ回復
- 料理はより効果が高い（想定）

## 14. インベントリ

- 持てるアイテム数: 上限あり（具体的な数は実装時に決定）
- 収納: 家に収納箱あり

## 15. セーブ機能

- ブラウザのローカルストレージを使用
- ゲーム進行を保存・読み込み可能
