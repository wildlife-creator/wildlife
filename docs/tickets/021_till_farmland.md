# チケット021: 畑を耕す

## 概要

クワを装備した状態で地面をクリックすると畑を耕せるようにする。

## 完了条件

- [ ] クワを装備して地面をクリックすると、そのタイルが畑になる
- [ ] 畑タイルは見た目が変わる（茶色の耕された土）
- [ ] クワを装備していないと耕せない（警告メッセージ表示）
- [ ] 畑にできるのは草タイルのみ（石や砂の上には作れない）
- [ ] クワの耐久度が1消費される

## 詳細

### 畑タイルの見た目

- 茶色の土に横線が入ったドット絵（耕された感じ）
- 通常の土タイルとは区別できるデザイン

### 操作

1. クワをインベントリから装備
2. 草タイルを左クリック
3. タイルが畑に変わる

### 制限

- 家の中では耕せない
- 資源オブジェクトがあるタイルには耕せない
- 既に畑のタイルは再度耕せない

## 依存

- チケット018が完了していること
