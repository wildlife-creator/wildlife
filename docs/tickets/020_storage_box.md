# チケット020: 収納箱

## 概要

家の中の収納箱にアイテムを保管できるようにする。

## 完了条件

- [ ] 室内の収納箱をクリックすると収納UIが開く
- [ ] 収納箱にアイテムを入れられる
- [ ] 収納箱からアイテムを取り出せる
- [ ] 収納箱の中身は保持される（家を出入りしても消えない）

## 詳細

### 収納箱の仕様

- スロット数: 30スロット
- インベントリと同じグリッド表示（5列×6行）

### UI仕様

- 画面にインベントリと収納箱が並んで表示される
- 左側: プレイヤーのインベントリ
- 右側: 収納箱の中身
- アイテムをクリックで移動（インベントリ→収納箱、収納箱→インベントリ）

### 操作

- 収納箱をクリック → 収納UI表示
- アイテムをクリック → 反対側に移動
- 画面外クリックまたはEscキー → 収納UIを閉じる
