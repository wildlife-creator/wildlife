# チケット019: 錬成システム

## 概要

集めた資源を使って道具やアイテムを作れる錬成（クラフト）システムを実装する。

## 完了条件

- [ ] 錬成メニューが開ける（Cキーまたはボタン）
- [ ] レシピ一覧が表示される
- [ ] 素材が足りているレシピはハイライト、足りないレシピはグレーアウト
- [ ] 錬成ボタンを押すと素材が消費されアイテムが作られる
- [ ] 作られたアイテムがインベントリに追加される

## 詳細

### レシピ一覧

| 作れるもの | 必要素材 |
|-----------|---------|
| 木の斧 | 木材×5 |
| 木のツルハシ | 木材×5 |
| 木のクワ | 木材×5 |
| 木の剣 | 木材×8 |
| 石の斧 | 石×3、木材×2 |
| 石のツルハシ | 石×3、木材×2 |
| 石のクワ | 石×3、木材×2 |
| 石の剣 | 石×5、木材×2 |
| 鉄の斧 | 鉄×3、木材×2 |
| 鉄のツルハシ | 鉄×3、木材×2 |
| 鉄のクワ | 鉄×3、木材×2 |
| 鉄の剣 | 鉄×5、木材×2 |
| 収納箱 | 木材×10 |

### UI仕様

- 画面中央にポップアップ表示
- 左側: レシピ一覧（スクロール可能）
- 右側: 選択中のレシピの詳細（必要素材と所持数）
- 下部: 「錬成する」ボタン
- 8bit風のデザイン

### 錬成の流れ

1. 錬成メニューを開く
2. レシピを選択
3. 素材が足りていれば「錬成する」ボタンが有効
4. ボタンを押すと素材が消費され、アイテムが作られる
5. インベントリに追加
