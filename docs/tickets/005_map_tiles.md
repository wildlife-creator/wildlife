# チケット005: マップとタイル表示

## 概要

タイルベースのマップを表示する。草原を基本とした地形。

## 完了条件

- [ ] マップがタイル（32x32のマス目）で構成される
- [ ] 草タイルで埋め尽くされた地面が表示される
- [ ] マップはCanvas より大きい（スクロール用の準備）

## 詳細

### マップ仕様

- タイルサイズ: 32x32ピクセル
- マップサイズ: 50x50タイル（1600x1600ピクセル）
- 初期状態: 全て草タイル

### map.js

- Mapクラスを作成
- 2次元配列でタイル情報を保持
- draw()メソッドで描画
- タイルの種類を定数で定義（GRASS = 0, DIRT = 1, など）

### タイル描画

- 最初は色付きの四角形でOK
- 草: 緑系
- ドット絵風に見えるよう、少し色にバリエーションをつけてもよい

## 依存

- チケット001が完了していること
