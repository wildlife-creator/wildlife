# チケット008: ブロック選択UI

## 概要

画面下部にブロック選択のUIを表示し、配置するブロックを選べるようにする。

## 完了条件

- [ ] 画面下部にブロック選択バーが表示される
- [ ] 石、土、砂、草、木の5種類から選択できる
- [ ] 選択中のブロックがハイライトされる
- [ ] 選択したブロックが配置される

## 詳細

### UI仕様

- 画面下部に横並びでブロックアイコンを表示
- 各ブロック: 48x48ピクセル程度
- 選択中は枠で囲むなどして強調

### ブロックの種類

| ID | 種類 | 色（仮） |
|----|------|---------|
| 1 | 石 | グレー |
| 2 | 土 | 茶色 |
| 3 | 砂 | ベージュ |
| 4 | 草 | 緑 |
| 5 | 木 | こげ茶 |

### 実装内容

- 選択中のブロックIDを保持する変数
- UIの描画（Canvas上またはHTML要素）
- クリックでブロック選択を切り替え

## 依存

- チケット007が完了していること
