# チケット007: ブロック配置システム

## 概要

右クリックでブロックを配置できるようにする。

## 完了条件

- [ ] 右クリックでタイルにブロックを配置できる
- [ ] 配置したブロックがマップ上に表示される
- [ ] 同じ場所に再度右クリックでブロックを削除できる

## 詳細

### 操作

- 右クリック: 選択中のブロックを配置
- 右クリック（既存ブロック上）: ブロックを削除

### 実装内容

- 右クリックイベントの取得
- クリック位置をタイル座標に変換
- マップデータを更新

### コンテキストメニュー

- 右クリック時のブラウザメニューを無効化

## 依存

- チケット006が完了していること
