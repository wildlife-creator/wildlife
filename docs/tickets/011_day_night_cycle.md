# チケット011: 時間システム（昼夜サイクル）

## 概要

ゲーム内の時間を管理し、昼夜サイクルを実装する。

## 完了条件

- [ ] ゲーム内時間が経過する（現実1分 = ゲーム内1時間）
- [ ] 画面右上に現在時刻が表示される（例: 14:00）
- [ ] 昼と夜で画面の明るさが変わる
- [ ] 夜は画面が暗くなる（半透明の黒オーバーレイ）

## 詳細

### 時間の仕様

- 現実1分 = ゲーム内1時間
- 1日 = 現実24分
- ゲーム開始時刻: 朝6:00

### 昼夜の区分

| 時間帯 | ゲーム内時間 | 画面の明るさ |
|--------|-------------|-------------|
| 朝 | 6:00〜8:00 | 徐々に明るくなる |
| 昼 | 8:00〜17:00 | 最も明るい（通常） |
| 夕方 | 17:00〜19:00 | 徐々に暗くなる、オレンジがかる |
| 夜 | 19:00〜6:00 | 暗い |

### UI仕様

- 位置: 画面右上
- テキスト: 白文字で「Day 1 - 14:00」のように表示
- 8bit風のフォントだとなおよい

### 実装内容

- timeManager.js を新規作成
- ゲーム内時間の管理
- 画面全体にオーバーレイを描画して明暗を表現

## 依存

- チケット001が完了していること
