# チケット023: 水やり

## 概要

植えた作物に水やりができるようにする。水やりをしないと作物が成長しない。

## 完了条件

- [ ] じょうろアイテムが存在する（錬成で作れる）
- [ ] じょうろを装備して作物タイルをクリックすると水やりできる
- [ ] 水やりしたタイルは見た目が変わる（土の色が濃くなる）
- [ ] 水やりの効果はゲーム内1日で切れる（毎日水やりが必要）
- [ ] 水やりされていない作物は成長しない

## 詳細

### じょうろの入手

- 錬成レシピに追加: じょうろ = 鉄×2 + 木材×3
- 耐久度: 無限（壊れない）

### 水やりの仕様

- じょうろを装備して作物が植わっている畑タイルをクリック
- 水やり済みのタイルは土の色がやや暗くなる
- ゲーム内の朝6:00に水やり状態がリセットされる
- 水やりされた日だけ成長カウントが進む

### UI

- 水やり済みタイル: 畑の色が暗い茶色に変化
- 未水やりタイル: 通常の畑の色

## 依存

- チケット022が完了していること
- チケット019が完了していること（錬成にじょうろレシピ追加）
