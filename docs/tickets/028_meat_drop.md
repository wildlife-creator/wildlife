# チケット028: 肉のドロップと食べる

## 概要

動物を倒すと肉をドロップし、食べて空腹を回復できるようにする。

## 完了条件

- [ ] 動物を倒すと肉アイテムがドロップする
- [ ] ドロップアイテムはマップ上に表示される
- [ ] プレイヤーがドロップアイテムの上を通ると自動で拾う
- [ ] 肉を食べると空腹度が回復する
- [ ] モンスターは肉をドロップしない

## 詳細

### ドロップアイテム

| 敵 | ドロップ | 個数 |
|----|---------|------|
| ウシ | 牛肉 | 2〜3 |
| ニワトリ | 鶏肉 | 1〜2 |
| ブタ | 豚肉 | 2〜3 |
| ゾンビ | なし | - |
| スケルトン | なし | - |

### ドロップの表示

- 敵が倒れた場所に小さなアイコンで表示
- アイコンは上下に軽く浮遊するアニメーション
- プレイヤーが1タイル以内に近づくと自動で拾う
- 30秒経過すると消える

### 肉の効果（生で食べた場合）

| 肉 | 空腹回復量 |
|----|-----------|
| 牛肉（生） | 10 |
| 鶏肉（生） | 8 |
| 豚肉（生） | 10 |

※料理すると回復量がアップ（フェーズ6で実装）

### 食べる操作

- インベントリから肉を選んで「食べる」ボタン
- チケット025と同じ仕組みを使用

## 依存

- チケット027が完了していること
- チケット025が完了していること
