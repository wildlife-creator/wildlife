# チケット016: マップ上に資源を配置

## 概要

マップ上に木、石、鉄鉱石などの資源オブジェクトを配置する。

## 完了条件

- [ ] マップ上に木が複数生えている
- [ ] マップ上に石の塊が複数配置されている
- [ ] マップ上に鉄鉱石が少数配置されている（石より希少）
- [ ] 資源オブジェクトは8bitドット絵風で描画される
- [ ] 資源オブジェクトには衝突判定がある（通り抜け不可）

## 詳細

### 資源の種類と配置

| 資源 | 見た目 | 出現頻度 | 配置場所 |
|------|--------|---------|---------|
| 木 | 緑の木（幹+葉） | 多い | マップ全体にランダム |
| 石 | 灰色の岩 | 普通 | マップ全体にランダム |
| 鉄鉱石 | 灰色+オレンジの岩 | 少ない | マップの端の方に多い |

### 配置ルール

- 家の周囲には配置しない（プレイヤーの行動範囲を確保）
- 資源同士が重ならないようにする
- マップ生成時にランダム配置

### 実装内容

- 資源オブジェクトクラスの作成
- マップ生成時の資源配置ロジック
- 資源の描画処理

## 依存

- チケット012が完了していること
