# チケット022: 種の入手と植える

## 概要

種アイテムを入手し、畑に植えられるようにする。

## 完了条件

- [ ] 草タイルを採集すると一定確率で種を入手できる
- [ ] 種は7種類（トマト、かぼちゃ、なす、いちご、さくらんぼ、もも、とうもろこし）
- [ ] 畑タイルに種を使うと作物が植えられる
- [ ] 植えた場所に種のアイコン（芽）が表示される

## 詳細

### 種の入手方法

- 草タイルを素手または道具でクリックすると採集
- 30%の確率でランダムな種を1つ入手
- 草タイル自体は消える（資源の枯渇）

### 種の種類

| 種 | アイコンの色 |
|----|------------|
| トマトの種 | 赤 |
| かぼちゃの種 | オレンジ |
| なすの種 | 紫 |
| いちごの種 | ピンク |
| さくらんぼの種 | 赤（小） |
| ももの種 | ピンク（薄） |
| とうもろこしの種 | 黄色 |

### 植える操作

1. インベントリから種を選択
2. 畑タイルをクリック
3. 種が1つ消費される
4. 畑タイル上に小さな芽のアイコンが表示される

### 制限

- 畑タイル以外には植えられない
- 既に作物が植わっているタイルには植えられない

## 依存

- チケット021が完了していること
- チケット015が完了していること
