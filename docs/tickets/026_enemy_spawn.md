# チケット026: 敵の出現

## 概要

マップ上に敵キャラクターを出現させる。昼は動物、夜はモンスターが出現する。

## 完了条件

- [ ] 昼間にマップ上に動物が出現する
- [ ] 夜間にマップ上にモンスター・ゾンビが出現する
- [ ] 敵はマップ上を自動で動き回る
- [ ] 敵は8bitドット絵風で描画される
- [ ] 昼夜の切り替わりで敵が入れ替わる

## 詳細

### 敵の種類

| 敵 | 出現時間 | 見た目 | 行動 |
|----|---------|--------|------|
| ウシ | 昼 | 茶色の四角＋角 | ゆっくり歩く、おとなしい |
| ニワトリ | 昼 | 白の小さい四角＋くちばし | ちょこちょこ歩く、おとなしい |
| ブタ | 昼 | ピンクの四角＋鼻 | ゆっくり歩く、おとなしい |
| ゾンビ | 夜 | 緑の人型 | プレイヤーに向かって歩く |
| スケルトン | 夜 | 白の人型 | プレイヤーに向かって歩く |

### 出現ルール

- プレイヤーの周囲（画面外の近い範囲）にランダム出現
- 家の中や家の近く（5タイル以内）には出現しない
- 同時出現数: 昼は最大5体、夜は最大8体
- プレイヤーから遠すぎる敵は自動で消える（画面外20タイル以上）

### 行動パターン

- 動物（昼）: ランダムに歩き回る。プレイヤーを攻撃しない
- モンスター（夜）: プレイヤーを見つけると近づいてくる

### 昼夜切り替え時

- 朝6:00: モンスターが消え、動物が出現開始
- 夜19:00: 動物が消え、モンスターが出現開始
