# チケット029: 環境ダメージ

## 概要

寒さ・暑さによる環境ダメージを実装し、体力が減るようにする。

## 完了条件

- [ ] 夜間は寒さダメージが発生する
- [ ] 長時間屋外にいると暑さダメージが発生する（昼の特定時間帯）
- [ ] 家の中にいるとダメージを受けない
- [ ] ダメージを受けているとき画面に警告アイコンが表示される

## 詳細

### 寒さダメージ

- 発生条件: 夜間（19:00〜6:00）に屋外にいる
- ダメージ: 30秒ごとに体力-2
- 家の中にいれば発生しない

### 暑さダメージ

- 発生条件: 真昼（11:00〜14:00）に屋外にいる
- ダメージ: 60秒ごとに体力-1
- 家の中にいれば発生しない

### 警告表示

- 寒さ: 画面端に雪の結晶アイコン + 「寒い！」テキスト
- 暑さ: 画面端に太陽アイコン + 「暑い！」テキスト
- 体力バーが点滅する

### バランス

- 環境ダメージは控えめに設定（メインは敵と空腹）
- プレイヤーに屋内外の行動計画を意識させる程度
