# チケット003: キャラクター移動（クリック移動）

## 概要

マウスクリックした位置にキャラクターが移動する機能を実装する。

## 完了条件

- [ ] Canvas上をクリックするとキャラクターがその位置に向かって移動する
- [ ] 移動はスムーズに行われる（瞬間移動ではない）
- [ ] 移動中に別の場所をクリックすると、新しい目的地に変更される

## 詳細

### 移動の仕様

- 移動速度: 1フレームあたり2〜4ピクセル程度（調整可能）
- 目的地に近づいたら停止（1ピクセル以内）

### 実装内容

- クリックイベントの取得
- 目的地座標の保存
- 毎フレーム、現在地から目的地に向かって少しずつ移動
- ゲームループの実装（requestAnimationFrame）

## 依存

- チケット002が完了していること
