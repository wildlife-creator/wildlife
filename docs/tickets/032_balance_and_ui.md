# チケット032: バランス調整とUI改善

## 概要

ゲーム全体のバランスを調整し、UIの使い勝手を改善する。

## 完了条件

- [ ] 空腹度の減少速度が適切（早すぎず遅すぎず）
- [ ] 敵の強さが適切（序盤で即死しない、でも緊張感がある）
- [ ] 資源の配置量が適切（すぐ枯渇しない、でも無限でもない）
- [ ] 各UIに操作説明が表示される
- [ ] 画面にミニガイドが表示される（初回プレイ時）

## 詳細

### バランス調整項目

| 項目 | 調整内容 |
|------|---------|
| 空腹減少速度 | ゲーム内1時間で5（1日で全部なくなるペース）が基準。プレイして調整 |
| 走り時の空腹消費 | 通常の1.5倍。走りすぎるとすぐお腹が減る |
| 敵の出現数 | 夜のモンスターが多すぎないか確認 |
| 環境ダメージ | 致命的でない程度に抑える |
| 道具の耐久度 | 頻繁に壊れすぎないか確認 |
| 作物の成長日数 | 3日（水やり日数）が長すぎないか確認 |
| 資源の再生 | 資源が枯渇した場合、一定時間後に新しい資源が出現する仕組みを追加 |

### 資源の再生

- ゲーム内3日ごとにマップの空きスペースに新しい資源が少量出現
- 木: 2〜3本、石: 1〜2個、鉄: 0〜1個
- 家や畑の近くには出現しない

### UI改善

- 操作ガイド: 画面右下に小さく表示
  - 「左クリック: 移動/アクション」
  - 「右クリック: ブロック配置」
  - 「I: インベントリ」
  - 「C: 錬成」
- 初回プレイ時のチュートリアルメッセージ
  - 「まずは周りの木や石を集めてみましょう」
  - 「夜は危険です。家に戻りましょう」
  - 数秒で消える吹き出し形式

### サウンド（余力があれば）

- BGMやSEは今回のスコープ外だが、将来追加しやすいよう設計しておく

## 依存

- チケット031が完了していること
