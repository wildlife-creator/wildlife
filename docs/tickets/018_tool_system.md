# チケット018: 道具システム

## 概要

道具の概念を実装し、インベントリから装備して使用できるようにする。

## 完了条件

- [ ] 道具アイテムが存在する（斧、ツルハシ、クワ、剣）
- [ ] インベントリから道具を選択して装備できる
- [ ] 装備中の道具が画面に表示される（プレイヤーの近くにアイコン表示）
- [ ] 道具によって採集速度が変わる
- [ ] ゲーム開始時に最低限の道具を所持している

## 詳細

### 道具の種類

| 道具 | 用途 | 効果 |
|------|------|------|
| 斧 | 木の伐採 | 木の採集速度が通常に（素手だと2倍遅い） |
| ツルハシ | 石・鉄の採掘 | 石・鉄の採集速度が通常に |
| クワ | 畑を耕す | 農業で使用（フェーズ4で接続） |
| 剣 | 敵への攻撃 | 戦闘で使用（フェーズ5で接続） |

### 初期所持品

- 木の斧 ×1
- 木のツルハシ ×1
- 木のクワ ×1

### 道具の素材ランク

| ランク | 素材 | 耐久度 | 効率 |
|--------|------|--------|------|
| 木 | 木材 | 低 | 1.0倍 |
| 石 | 石 | 中 | 1.5倍 |
| 鉄 | 鉄 | 高 | 2.0倍 |

### 耐久度

- 道具には耐久度がある
- 使用するたびに耐久度が1減る
- 耐久度がゼロになると壊れる（インベントリから消える）
- 木: 30、石: 60、鉄: 120

### UI

- 装備スロット: インベントリの横に1つ
- 装備中の道具名を表示

## 依存

- チケット015が完了していること
- チケット017が完了していること
