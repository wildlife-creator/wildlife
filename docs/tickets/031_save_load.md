# チケット031: セーブ・ロードシステム

## 概要

ゲームの進行状況をブラウザのローカルストレージに保存し、再開できるようにする。

## 完了条件

- [ ] セーブボタンでゲームの状態を保存できる
- [ ] ゲーム起動時にセーブデータがあれば「続きから」を選べる
- [ ] ロードすると保存時の状態から再開できる
- [ ] 「新しく始める」を選ぶとセーブデータを消して最初からプレイできる

## 詳細

### 保存するデータ

- プレイヤーの位置
- 体力・空腹度
- インベントリの中身
- 装備中の道具
- 収納箱の中身
- マップの状態（配置したブロック、畑、作物の成長状態）
- 資源オブジェクトの状態（残っているもの）
- ゲーム内時間（Day、時刻）
- 現在のシーン（屋外 or 室内）

### セーブの方法

- 画面上にセーブボタンを配置
- クリックで即座に保存
- 保存完了時に「セーブしました」と一瞬表示

### タイトル画面

- ゲーム起動時にタイトル画面を表示
- 「ワイルドライフ」のタイトルロゴ（8bit風テキスト）
- セーブデータがない場合: 「はじめから」ボタンのみ
- セーブデータがある場合: 「つづきから」「はじめから」の2つ
- 「はじめから」を選ぶと確認ダイアログ（セーブデータがある場合）

### ローカルストレージ

- キー: "wildlife_save"
- 値: JSON形式でシリアライズ
- データサイズに注意（マップデータが大きくなりすぎないよう）

## 依存

- 全チケット（001〜030）が完了していること
