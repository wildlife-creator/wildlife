# チケット002: キャラクター表示

## 概要

プレイヤーキャラクターをCanvas上に表示する。

## 完了条件

- [ ] プレイヤーキャラクター（仮のドット絵）が画面中央に表示される
- [ ] キャラクターは16x16または32x32ピクセルのドット絵風
- [ ] 8bit風の見た目になっている

## 詳細

### player.js

- Playerクラスを作成
- x, y座標のプロパティ
- draw()メソッドで描画
- 最初は四角形で仮表示でOK（後で画像に差し替え）

### 描画仕様

- サイズ: 32x32ピクセル
- 色: 仮で青や緑など目立つ色
- 位置: Canvas中央

## 依存

- チケット001が完了していること
