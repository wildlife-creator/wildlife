# チケット030: 料理システム

## 概要

家の中の調理台で食材を組み合わせて料理を作れるようにする。料理は生の食材より回復量が高い。

## 完了条件

- [ ] 室内の調理台をクリックすると料理UIが開く
- [ ] レシピ一覧が表示される
- [ ] 素材が足りているレシピはハイライト、足りないレシピはグレーアウト
- [ ] 料理ボタンを押すと素材が消費され料理が作られる
- [ ] 料理を食べると生の食材より多く空腹度が回復する

## 詳細

### 料理レシピ

| 料理 | 必要素材 | 空腹回復量 |
|------|---------|-----------|
| 焼き牛肉 | 牛肉×1 | 25 |
| 焼き鶏肉 | 鶏肉×1 | 20 |
| 焼き豚肉 | 豚肉×1 | 25 |
| 野菜サラダ | トマト×1、なす×1 | 30 |
| 野菜スープ | かぼちゃ×1、とうもろこし×1 | 35 |
| フルーツ盛り | いちご×1、さくらんぼ×1、もも×1 | 35 |
| 特製シチュー | 牛肉×1、かぼちゃ×1、トマト×1 | 50 |

※参考: 生の肉は10程度、生の野菜は8〜20程度の回復量

### UI仕様

- 錬成システム（チケット019）と同様のレイアウト
- 左側: レシピ一覧
- 右側: 選択中のレシピ詳細（必要素材と所持数）
- 下部: 「料理する」ボタン
- 8bit風のデザイン

### 料理の流れ

1. 室内で調理台をクリック
2. 料理UIが表示される
3. レシピを選択
4. 素材が足りていれば「料理する」ボタンが有効
5. ボタンを押すと素材が消費され、料理アイテムがインベントリに追加

### 料理アイテム

- インベントリに通常のアイテムとして格納
- 食べる操作はチケット025と同じ仕組み
