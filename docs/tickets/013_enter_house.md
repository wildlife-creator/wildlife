# チケット013: 家の中に入る

## 概要

家の入口をクリックすると、家の中に入れる。

## 完了条件

- [ ] 家の入口付近でクリックすると家の中に入れる
- [ ] 家の中は別画面（室内画面）として表示される
- [ ] 室内にはベッド、収納箱、調理台がある（見た目のみ、機能は後のチケット）
- [ ] 家の入口をクリックすると外に出られる

## 詳細

### 室内画面の仕様

- 家の中は固定画面（スクロールなし）
- 8bitドット絵風の室内
- ベッド: 左側に配置
- 収納箱: 右側に配置
- 調理台: 上側に配置
- 出口: 下側に配置

### 画面遷移

- 外の世界 → 入口クリック → 室内画面
- 室内画面 → 出口クリック → 外の世界（家の前に出る）

### 実装内容

- 室内シーンの管理（シーン切り替え）
- 室内の描画
- 入口/出口の判定

## 依存

- チケット012が完了していること
