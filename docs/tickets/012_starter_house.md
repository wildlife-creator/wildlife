# チケット012: 初期の家

## 概要

ゲーム開始時にマップ上に簡素な家を配置する。

## 完了条件

- [ ] マップ上に家が表示される（8bitドット絵風）
- [ ] 家はプレイヤーの初期位置の近くに配置
- [ ] 家は衝突判定があり、壁を通り抜けられない
- [ ] 家の入口は明確にわかるようにする

## 詳細

### 家の見た目

- 5x5タイル程度のサイズ
- 壁: 木の色（茶色系）
- 屋根: 赤系または青系
- 入口: 下側の中央に1タイル分の開口

### 配置

- マップの中央付近
- プレイヤーの初期位置から近い場所

### 衝突判定

- 壁タイルには衝突判定を設定
- 入口部分は通行可能

### 実装内容

- 家のタイルデータを定義
- マップ生成時に家を配置
- 壁タイルの衝突判定を追加

## 依存

- チケット005が完了していること
- チケット006が完了していること
