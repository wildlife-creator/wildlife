# チケット024: 作物の成長

## 概要

植えた作物がゲーム内時間の経過とともに成長し、見た目が変化する。

## 完了条件

- [ ] 作物が段階的に成長する（4段階）
- [ ] 各成長段階で見た目が変わる
- [ ] 水やりされた日だけ成長が進む
- [ ] 最終段階になると収穫可能になる
- [ ] 収穫可能な作物は見た目でわかる（実がなっている）

## 詳細

### 成長段階

| 段階 | 見た目 | 必要日数（水やり日数） |
|------|--------|---------------------|
| 1. 芽 | 小さな緑の点 | 植えた直後 |
| 2. 苗 | 小さな茎と葉 | 1日後 |
| 3. 成長中 | 大きな茎と葉 | 2日後 |
| 4. 収穫可能 | 実がなっている（色は作物による） | 3日後 |

### 作物ごとの見た目（収穫可能時）

| 作物 | 実の色 |
|------|--------|
| トマト | 赤い丸 |
| かぼちゃ | オレンジの大きな丸 |
| なす | 紫の楕円 |
| いちご | 小さな赤い三角 |
| さくらんぼ | 赤い小さな丸×2 |
| もも | ピンクの丸 |
| とうもろこし | 黄色の縦長 |

### 成長の判定タイミング

- 毎朝6:00に成長判定
- 前日に水やりされていた場合のみ成長段階が1つ進む
- 水やりされていなかった場合は成長しない（枯れはしない）

## 依存

- チケット023が完了していること
- チケット011が完了していること
