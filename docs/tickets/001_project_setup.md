# チケット001: プロジェクト初期設定

## 概要

ゲーム開発の基盤となるファイル構成を作成する。

## 完了条件

- [ ] index.html が作成されている
- [ ] css/style.css が作成されている
- [ ] js/main.js が作成されている
- [ ] ブラウザで開くと「Wildlife」というタイトルが表示される
- [ ] Canvasが画面に表示される（800x600px）

## 詳細

### index.html

- HTML5のベース構造
- Canvas要素を配置
- CSSとJSファイルを読み込む

### style.css

- Canvasを中央配置
- 背景色を設定（ダークグレーなど）
- ドット絵がぼやけないようにimage-rendering設定

### main.js

- Canvas要素を取得
- 2Dコンテキストを取得
- コンソールに「ゲーム開始」と表示
