# チケット017: 資源の採集

## 概要

資源オブジェクトをクリックして資源を採集し、インベントリに入れる。

## 完了条件

- [ ] 資源オブジェクトをクリックすると採集が始まる
- [ ] 採集には時間がかかる（プログレスバー表示）
- [ ] 採集完了で資源がインベントリに入る
- [ ] 資源オブジェクトは採集後にマップから消える
- [ ] 採集量は資源の種類によって異なる

## 詳細

### 採集の仕様

| 資源 | 採集時間 | 獲得アイテム | 獲得数 |
|------|---------|------------|--------|
| 木 | 2秒 | 木材 | 3〜5 |
| 石 | 3秒 | 石 | 2〜4 |
| 鉄鉱石 | 4秒 | 鉄 | 1〜2 |

### 採集の流れ

1. 資源オブジェクトをクリック
2. プレイヤーが資源の近くに移動
3. プログレスバーが表示され、採集開始
4. 採集完了 → アイテムがインベントリに追加
5. 資源オブジェクトが消える

### プログレスバー

- 資源オブジェクトの上に表示
- 緑色のバーが左から右に伸びる

### 道具による効率化（後のチケットで接続）

- 素手でも採集可能だが時間が2倍かかる
- 適切な道具を持っていると通常速度で採集
