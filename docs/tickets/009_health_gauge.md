# チケット009: 体力ゲージ

## 概要

プレイヤーの体力をゲージで画面上に表示する。

## 完了条件

- [ ] 画面左上に体力ゲージが表示される
- [ ] 体力は数値（例: 100/100）でも表示される
- [ ] 体力ゲージは赤色系のバーで表現
- [ ] 体力が減ると、ゲージが短くなる
- [ ] 体力がゼロになると家に強制帰還（家の実装後に接続）

## 詳細

### 体力の仕様

- 最大値: 100
- 初期値: 100
- 減少要因: 空腹、敵の攻撃、環境ダメージ（後のチケットで接続）
- 回復方法: 睡眠（後のチケットで接続）

### UI仕様

- 位置: 画面左上（カメラに追従しない固定UI）
- バーの幅: 200px程度
- バーの高さ: 20px程度
- 背景: 暗い赤、ゲージ: 明るい赤
- テキスト: 白文字で「HP: 100/100」

### 実装内容

- Playerクラスにhealthプロパティを追加
- ゲージ描画関数の作成
- テスト用に一定時間で体力が減る仕組み（後で削除可）

## 依存

- チケット002が完了していること
