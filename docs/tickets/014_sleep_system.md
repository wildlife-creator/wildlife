# チケット014: 睡眠システム

## 概要

家の中のベッドで睡眠し、体力回復と夜スキップを実装する。

## 完了条件

- [ ] 室内でベッドをクリックすると睡眠できる
- [ ] 睡眠すると体力が全回復する
- [ ] 睡眠すると時間が翌朝6:00まで進む（夜スキップ）
- [ ] 睡眠中は画面が暗転し「zzz...」などの演出がある
- [ ] 体力ゼロ時は自動的に家に帰還して強制睡眠

## 詳細

### 睡眠の効果

- 体力: 最大値まで回復
- 空腹: 変化なし（減らない、増えない）
- 時間: 翌朝6:00まで進む

### 自発的睡眠

- ベッドをクリックで実行
- いつでも寝られる（昼でもOK）

### 強制睡眠（体力ゼロ時）

- 体力がゼロになると画面が暗転
- 自動的に家の中（ベッド）に移動
- 体力が50%まで回復して翌朝に目覚める（ペナルティとして全回復ではない）

### 演出

- 画面がゆっくり暗くなる
- 「zzz...」のテキストまたはアニメーション
- 翌朝、画面がゆっくり明るくなる
