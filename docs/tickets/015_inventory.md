# チケット015: インベントリシステム

## 概要

プレイヤーが資源やアイテムを持ち運べるインベントリ（持ち物）を実装する。

## 完了条件

- [ ] 画面にインベントリUIが表示される（Iキーまたはボタンで開閉）
- [ ] アイテムをスロットに格納できる
- [ ] スロット数に上限がある（最大20スロット）
- [ ] 各スロットにアイテムのアイコンと個数が表示される
- [ ] インベントリが満杯のときは新しいアイテムを拾えない（警告表示）

## 詳細

### UI仕様

- グリッド形式（4列×5行 = 20スロット）
- 各スロット: 48x48ピクセル程度
- アイテムのドット絵アイコン + 右下に個数表示
- 8bit風のデザイン

### アイテムデータ構造

- id: アイテムID
- name: アイテム名
- type: カテゴリ（resource, tool, food）
- icon: 表示用の色/形
- stackable: スタック可能か
- maxStack: 最大スタック数（資源は64、道具は1）

### 操作

- クリックでアイテム選択
- 選択中のアイテムは枠でハイライト
- 食べ物を選択して「食べる」ボタンで消費（後のチケットで接続）
