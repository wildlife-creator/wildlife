# チケット025: 収穫と食べる

## 概要

成長した作物を収穫してインベントリに入れ、食べて空腹を回復できるようにする。

## 完了条件

- [ ] 収穫可能な作物をクリックすると収穫できる
- [ ] 収穫した作物がインベントリに入る
- [ ] 収穫後、畑タイルは空の畑に戻る（再度種を植えられる）
- [ ] インベントリから食べ物を選んで食べると空腹度が回復する
- [ ] 収穫時に一定確率で種も一緒に入手できる（次の栽培用）

## 詳細

### 収穫

- 成長段階4（収穫可能）の作物をクリック
- 作物アイテムが1〜3個インベントリに追加
- 50%の確率で同じ種類の種を1つ追加入手
- 畑タイルは耕された状態に戻る

### 食べ物の効果

| 食べ物 | 空腹回復量 |
|--------|-----------|
| トマト | 15 |
| かぼちゃ | 20 |
| なす | 15 |
| いちご | 10 |
| さくらんぼ | 8 |
| もも | 12 |
| とうもろこし | 18 |

### 食べる操作

1. インベントリを開く
2. 食べ物をクリックして選択
3. 「食べる」ボタンをクリック（またはダブルクリック）
4. アイテムが1つ消費され、空腹度が回復
5. 回復量が画面に一瞬表示される（「+15」など）

### 制限

- 空腹度が100（最大）のときは食べられない（「お腹がいっぱいです」表示）

## 依存

- チケット010が完了していること
